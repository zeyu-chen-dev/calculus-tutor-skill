# 辅导案例

现有两份案例均为维护者编写的**模拟教学片段**，用于说明期望行为；不是学生真实对话，也不是模型实测结果。成功片段仅示范当前障碍得到回应，不证明学生已经掌握或成绩提高。

- [01-exponential.md](01-exponential.md)：不知道为什么想到同除；区分方法选择与操作执行。
- [02-equivalence.md](02-equivalence.md)：回到指定理解断点；说明等价替换在抵消结构中的风险。

## 真实案例进入仓库之前

只公开参与者同意公开的片段。删除姓名、学号、账号、联系方式、私人课程信息，以及可能间接识别个人的细节；不提交原始导出文件。涉及第三方材料时，还需确认可以公开使用该材料；必要时改写题目并标注。

脱敏后仍由贡献者确认可公开的版本。若改写了 AI 或学生发言，分别标为“整理转述”或“改进示例”，不能冒充原话。未经对话参与者确认，不把私下辅导授权推定为公开授权。

## 每个案例的最小格式

1. **来源类型：** 真实脱敏 / 整理改写 / 模拟。真实材料写明公开授权已确认，不公布授权中的私人信息。
2. **学习背景：** 仅记录相关先修知识与本题目标。
3. **题目与卡点：** 保留趋近条件和学生最后理解的位置。
4. **原始片段：** 分清学生与 AI；未取得原文时不伪造引文。
5. **教学分析：** 为什么这次没想到？这是观察还是假设？
6. **改进片段：** 标为建议改写，展示结构、理由和学生小任务。
7. **结果与边界：** 只写实际观察到的后续表现；没有后续就写未验证。
8. **对应规则：** 指向具体教学规则或题型，说明是否推动规则更新。

不要求案例一定包含失败与成功的真实对照。如果只有一次失败记录，就保留失败事实，再单独给出建议改写；不要编造学生学会后的回应。
