# calculus-tutor-skill

[English](README_EN.md) · [教学演示](DEMO.md) · [参与贡献](CONTRIBUTING.md) · [验证状态](evals/STATUS.md)

**看懂 AI 的解答，下一题还是不会起步？**

calculus-tutor-skill 是面向大学生的高等数学 AI 辅导 Skill：找准学生卡在哪里，解释为什么想到某一步，再把关键的一小步交还给学生。提供入门、课后巩固、进阶、期末突击、预习和标准答案六种模式。

项目源于发起者学习高数时与 AI 的真实对话经验。我们关心的不只是答案是否正确，还包括：**学生为什么没有想到这一步？这次解释之后，下次能否自己想到？**

当前版本：[v0.1.0-alpha](https://github.com/zeyu-chen-dev/calculus-tutor-skill/releases/tag/v0.1.0-alpha)，公开预览版。入口格式检查通过，已观察到一次带选项的模式选择与课后巩固交互片段；完整场景、跨平台与学习效果尚未验证。现有公开案例均为模拟。采用 [MIT License](LICENSE)，版权署名为 `zeyu-chen-dev`；详见 [验证状态](evals/STATUS.md)。

## 三步试用

1. 下载或克隆本仓库，保留文件夹中的 `SKILL.md` 及参考资料。
2. 在能读取本地文件的 AI Agent 中，让它读取 `SKILL.md`；普通聊天环境可粘贴正文，并提供本次相关参考片段。
3. 发题并选择模式；也可以在第一条题目消息中直接写“使用课后巩固模式”。选定后持续沿用，随时可改。

可以直接使用这段请求：

> 请读取本文件夹的 SKILL.md，按课后巩固模式辅导我。求 lim(n→∞) (2^n+3^n)/(3^n+1)。我会执行同除，但不知道为什么想到除以 3^n。先解释这个卡点。

这是指令与参考资料包，当前无需运行项目程序或配置 API Key。原生选项框和跨会话存储取决于宿主能力；没有文件读取功能时需要手动提供内容。

## 看看讲解有什么不同

以“为什么想到除以 $3^n$”为例，入门模式会把“比较相对大小”与变形连接起来，再留一步让学生完成；期末突击模式给套路与完整过程；标准答案模式只输出规范解答。

查看 [同一道题的三种输出演示](DEMO.md)。这些片段是明确标注的模拟示例，用于理解设计；实际行为还需要继续试用验证。

## 项目目标与范围

主要面向大学高等数学基础尚不扎实、看得懂解答却不会独立起步的学生。第一阶段以极限与无穷小为试点，用真实教学反馈修正规则；之后扩展到导数与积分。当前规则可用于其他高数主题，但参考题型与案例覆盖有限。

本项目交付可复用的教学指令、方法识别资料和辅导案例。第一阶段不开发独立 App、题库平台、自动评分系统或训练模型。

## 设计原则

1. **诊断先于推进。** 从学生已有步骤寻找障碍；诊断可随回答修正。
2. **同时解释选择与合法性。** “为什么想到同除”与“为什么可以同除”是不同问题。
3. **逐步撤去帮助。** 从提示、半完成示例走向独立完成，不以追问次数衡量效果。
4. **回退到理解断点。** 学生说某处不懂，就在该处补桥，不继续加新内容。
5. **方法有边界。** 识别信号只能提出候选方法，不能代替条件检查。
6. **模式由学生选择。** 首题先选择，当前对话持续沿用；逐步教学、期末突击和标准答案各按约定输出。
7. **用证据形成复习重点。** 区分一次失误、反复卡点、提示后完成、独立迁移。
8. **真实、克制地使用学习记录。** 不假装跨会话记忆；私人记录不进入公开案例。

## 现在如何试用

### 六种模式与选择规则

| 模式 | 主要输出 |
| --- | --- |
| 入门 `beginner` | 细讲知识点，分步引导，完成关键小步骤 |
| 课后巩固 `practice` | 连接课堂知识、题目识别与做题技巧 |
| 进阶 `master` | 精简基础说明，比较方法，按需拓展高阶解法 |
| 期末突击 `deadliner` | 面向平时投入少、期末突击的学生，给套路、技巧和完整解题过程 |
| 预习 `previewer` | 先建立概念与知识联系，配基础例子，减少复杂技巧训练 |
| 标准答案 `straight` | 仅给可以直接誊抄的规范解题过程和结论，无教学讲解与额外内容 |

新对话收到第一道题时先选模式，并告知随时可以更改。首题已明确指定模式则直接采用；选定后保留原题接着处理，不要求重发。之后不因换题而重问，直到用户主动切换。作答出现独立完成、解释条件等优秀表现时，可询问是否调整，不能自动切换；`straight` 不主动推荐切换。

支持原生选项提问的宿主优先显示六选一选择框，每项附一句说明；不支持时使用文字编号，回复编号或名称即可。选择框由宿主渲染，Skill 文件本身不提供固定界面。预选但未提交不视为学生已经选择，具体可用工具与外观需在目标宿主中验证。

必要的数学条件和证明语句属于标准答案正文；`straight` 不是只报最终结果。图片无法辨认或题设有关键缺失时，仍需最简澄清。细则见 [SKILL.md](SKILL.md)。

### 普通对话环境

把 `SKILL.md` 的正文作为辅导指令提供给 AI，并把相关参考文件加入其可读取的上下文；若环境不能读取文件，直接粘贴本次相关片段。提示示例：

> 请按 calculus-tutor-skill 的入门模式辅导我。我刚开始学极限，还没学泰勒展开。题目是 lim(n→∞) (2^n+3^n)/(3^n+1)。我看见答案要除以 3^n，但不知道为什么想到这样做。先从这里解释。

复习时可以说：

> 请进入复习模式。这是我带来的学习记录……先帮我找一个最值得补的卡点，再出一道相近题检查。

没有参考文件时，AI 仍可使用核心规则；需要详细复习格式或案例时，应说明缺少材料，不能假装读过。

### 支持 Skill 的 Agent

以本文件夹为 Skill 包，保留 `SKILL.md` 和相对路径引用。入口采用 YAML `name`、`description` 加 Markdown 正文；参考资料按需加载。这与 [OpenAI 官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills) 描述的入口结构一致。

Codex 本地项目试用可将整个文件夹放到目标项目的 `.agents/skills/calculus-tutor-skill/`，再明确调用 `$calculus-tutor-skill`。具体发现位置与调用方式以所用宿主版本为准，参见同一官方文档。此草稿交付不会自动安装到你的全局配置。

### 兼容策略与当前验证边界

| 环境 | 接入方式 | 当前状态 |
| --- | --- | --- |
| 普通聊天模型 | 手动提供规则正文和相关参考资料 | 待在具体宿主中验证；尚无对照实验 |
| 当前 Codex 开发聊天 | 显式读取本地规则，再按规则交互 | 已观察到选项提交与课后巩固片段；未验证自动发现、独立新对话及完整教学效果 |

| 其他 Agent / Skill 宿主 | 保持教学正文，按其规范转换元数据和资源加载方式 | 待选定平台并查阅官方规范验证 |

教学逻辑不依赖特定模型、MCP、联网或持久记忆工具。可读 Markdown 不等于所有宿主都能自动发现并完整执行 Skill；跨会话记忆取决于宿主能力与学生选择。

## 如何判断“更会教”

人工运行 [验收场景](evals/scenarios.md)，同时查看数学正确性与教学行为：是否回应实际卡点、解释方法来源、提供合适支架、让学生完成有价值的小步骤、准确描述掌握证据。

答案正确只是必要条件。教学模式中，学生说“懂了”不能单独证明学会；观察其能否在减少提示后完成相近题。`deadliner` 检查套路能否执行、过程是否完整；`straight` 检查标准解答是否正确完整且没有额外内容，不强加教学问答，也不据此推测学生掌握程度。当前不宣称提高多少分或达到某个学习效果。

## 迭代路线

- **v0.1.0-alpha：** 许可证已确定；完成文件检查后，以预览版开放规则和模拟案例，明确列出尚未验证的行为，邀请小范围试用。
- **首个完整试用版：** 运行全部验收场景，整理至少一组经授权脱敏的真实案例，修正实际失败后更新版本与验证记录。
- **v0.2：** 根据极限辅导中的重复失败更新规则和案例，验证薄弱点记录能否改善后续复习安排。
- **后续：** 扩展导数与积分；对选定的第二种宿主做相同场景验证，再决定是否增加适配层。

规则改动应带一个具体失败现象和预期行为；先修正窄问题，再判断是否需要通用原则。教学行为变化记录在版本说明中，不能只改提示词却沿用旧的验证结论。
